
No Vanilla Progression
=======

This mod is made to create a more realistic slower paced progression from minecraft. Inspired from [No Tree Punching](https://github.com/alcatrazEscapee/no-tree-punching?tab=readme-ov-file), by [alcatrazEscapee](https://github.com/alcatrazEscapee), it funchion mostly the same as it's predecessor before the midgame progression where it becomes different.

Added & Removed:
============
- Vanilla recipes of wooden and stone tools are removed.
- Axe recipes for spilting wood into a few planks
- Saw recipes for spilting wood into a many planks
- Flint pickaxe, axe, shovel, hoe, & knife a early game tool set that is stronger then copper but slower.
- New copper and bronze tool on the level of stone equipment.
- Blocks & items like raw tin, tin ingots, tin blocks, bronze ingots, & bronze blocks
